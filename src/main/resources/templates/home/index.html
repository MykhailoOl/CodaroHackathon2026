How it works

Four calm steps

1. Choose a home

Select a funeral home and a chapel, hall, garden, cremation suite, or reception room.

2. Set the arrangement

Pick a ceremony type and package, then add extras such as flowers, music, or catering.

3. Confirm the arrangement

After you confirm, currently available dates appear on a wheel while a time is assigned. The server chooses the date.

4. Manager confirms

Family arrangements stay pending until a manager confirms. You can follow status in History and Notices.

Privacy

Family details stay private

Names of the deceased, dates of birth and death, family notes, phone numbers, and emails are never written to application logs. Sensitive fields are not stored in the arrangement guide’s browser storage.

Date assignment

The wheel is a visual of currently free dates. The assigned time is chosen on the server from live availability after you confirm. The quoted amount does not change with the assigned date.
